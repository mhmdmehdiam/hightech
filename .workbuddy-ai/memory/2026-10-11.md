- اسکرین‌شات headless کروم با `--window-size` کوچک‌تر از ~۵۰۰px چیدمان را اشتباه نشان می‌دهد. برای تست موبایل از iframe با عرض ۳۹۰px استفاده شد.

## فاز چهارم — بازنویسی کامل با Next.js 16 + پنل مدیریت
- پروژه‌ی جدید: `D:/پروژه دانشگاه/high-tech-next/` (پروژه‌ی HTML قدیمی در `high-tech/` دست‌نخورده مانده).
- استک: Next.js 16.4 (App Router) + React 19.3 + TypeScript + Three.js 0.186 / @react-three/fiber 9.8 / drei 10.7 + GSAP 3.15. فونت Vazirmatn با `next/font/google`.
- **Next.js 16 نکات مهم**: Turbopack پیش‌فرض، `middleware` → `proxy.ts`، پارامترها/`cookies`/`headers` async، `LayoutProps<'/'>` و `PageProps<'/path'>` تایپ‌های گلوبال، و **Cache Components پیش‌فرض فعال** — `export const dynamic` ممنوع است؛ به‌جایش `export const instant = false` روی روت‌های داده‌محور.
- لایوت ریشه عمداً بدون خواندن داده است (تا `/admin/login` استاتیک بماند)؛ خواندن تنظیمات در `app/(site)/layout.tsx` انجام می‌شود.
- بک‌اند: چون کاربر پنجره‌ی تأیید سرویس ابری را بست (`useLocalImplementation: true`)، پیاده‌سازی محلی ساخته شد — Route Handler های Next + ذخیره در فایل JSON در `data/`. فایل‌ها: `products.json`, `posts.json`, `orders.json`, `settings.json`, `categories.json`, `users.json`, `session.secret`.
- احراز هویت مدیر: `lib/auth.ts` با HMAC روی کوکی httpOnly + رمز هش‌شده با scrypt. دسترسی پیش‌فرض `admin` / `hightech1404`.
- **آسیب‌پذیری رفع‌شده**: بدون `proxy.ts`، محتوای داشبورد در HTML استریم می‌شد حتی وقتی لایوت ریدایرکت می‌کرد (نشتی داده). `proxy.ts` حالا قبل از رندر، درخواست بدون کوکی را ۳۰۷ می‌کند.
- پنل مدیریت `/admin`: داشبورد، محصولات (CRUD + آپلود تصویر)، مقالات، سفارش‌ها، تنظیمات سایت (۸ تب: برند، اسلایدر، بخش‌های صفحه اصلی، ارسال/پرداخت/تخفیف، تماس، فوتر، سئو، رمز عبور).
- وبلاگ: لیست با مقاله ویژه/دسته‌بندی/جستجو + صفحه‌ی مقاله با فهرست مطالب چسبان، نوار پیشرفت مطالعه، اشتراک‌گذاری، برچسب‌ها و محصول مرتبط. ویرایشگر مقاله از مارک‌آپ ساده (`##`, `-`, `**`) پشتیبانی می‌کند (`lib/markup.ts`).
- PWA: `manifest.webmanifest`, `sw.js` (cache-first برای استاتیک، network-first برای صفحات، بدون کش برای /admin و /api)، `offline.html` و بنر نصب.
- ۲۸ روت در بیلد. تصاویر: `public/products/ht-*.webp` (۱۶) + آیکون‌های PWA تولیدشده با اسکرین‌شات headless.
- اجرا: `cd high-tech-next && npm run dev` (یا `npm run build && npm start`).

### نکته‌ی مهم محیطی (تکرارشدنی)
- `--disable-gpu` در اسکرین‌شات headless باعث رندر نادرست WebGL می‌شود (بوم سه‌بعدی روی محتوا می‌افتد و صفحه تیره دیده می‌شود). برای صفحات دارای WebGL باید **بدون** `--disable-gpu` عکس گرفت.
- انیمیشن‌های GSAP که `opacity` را از صفر شروع می‌کنند در محیط تست کامل نمی‌شوند و محتوا نامرئی می‌ماند. راه‌حل: فقط `transform` انیمیت شود (هرگز opacity برای محتوای حیاتی).
