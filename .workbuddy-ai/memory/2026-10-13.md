# 2026-10-13 — zajno motion study + port to High Tech

## What was done

Studied `https://zajno.com` (screen recording + DOM/CSS/JS extraction) and ported its
motion language onto `high-tech-next`.

### Key finding about zajno
- **No GSAP, no Three.js, no Lenis, no Framer.** All motion is **CSS transition +
  a class flip (`fx`)**. The 3D hero is a hand-written raw WebGL canvas (`RGL` class)
  drawing video-as-texture.
- Three shared easings carry the whole site:
  `--o3 cubic-bezier(.215,.61,.355,1)` · `--o6 cubic-bezier(.19,1,.22,1)` (house curve)
  · `--io6 cubic-bezier(.16,1,.3,1)`
- Durations: 300 (text) / 400 / 600 (hero) / 800 (clip-path) / 1800ms (heavy entrances).
- Palette: `#1a1a1a` dark, `#ff3928` red accent, `#f2f2f0` bg.
- Signature move: a work-index table where hovering a row inverts it to red and a
  **preview card follows the cursor** (`position:fixed` + `translate3d`, `clip-path: inset()` reveal).

### What was implemented in high-tech-next
CSS (`app/globals.css`):
- Motion tokens added to `:root`: `--ease-out/--ease-expo/--ease-quint`,
  `--t-fast/mid/slow/reveal/heavy`, `--accent:#ff3928`
- New utility classes: `.clip`, `.clip-img`, `.sweep` (two-layer underline),
  `.heavy-in`, `.hero-media`, `.li-shift`
- `.wi / .wi-row / .wi-preview` — the work-index table + floating preview
- Product grid lift on hover

Components:

  written once per rAF (never `top/left`)
- `components/ScrollParallax.tsx` (new) — rAF-throttled scroll lift/fade
- `components/RevealObserver.tsx` — selector widened to also observe
  `.clip`, `.clip-img`, `.heavy-in`
- `Hero3D.tsx` — added `hero-media fx` for the scale-in lift
- `Footer.tsx` — `.sweep` on column links

## Tech gap zajno vs ours (conclusion)
zajno has NO libraries — it hand-wrote its whole stack. Things we lack:
1. Raw hand-written WebGL engine (`RGL`/`Ren`/`Pgm`/`Geo`/`Tex`/`Cam`/`M4`) — we use Three.js instead
2. Hand-written GLSL shaders (14 uniforms) incl. a `Kinetic` flash-buffer effect that
   smears/stretches content during fast scroll (texture stored in a framebuffer)
3. Video-as-texture on a 3D plane (`texImage2D(..., video.dom)`) — we use plain `<video>`/`<img>`
4. Custom inertial smooth-scroll (`Kinetic` + `velDamping` + 33×Lerp/23×Damp)
5. Page transitions via `is-leaving`/`is-active` overlay + `history.pushState` SPA routing

Things we have that zajno does NOT: GSAP, Three.js/R3F/drei, Next.js 16 (SSR/RSC/PPR),
TypeScript, PWA service worker, API routes/backend, React 19.

Decision: NOT worth porting their WebGL engine. Worth borrowing (in priority order):
page-transition overlay > smooth-scroll inertia > shader fast-scroll smear.
